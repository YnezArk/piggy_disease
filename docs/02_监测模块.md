# 02 监测模块（`monitor/`）

> 任务：从连续音频中识别“咳嗽/非咳嗽”，输出事件时间戳、频次和预警级别。  
> 代码：`monitor/src/`、`monitor/scripts/`；模型：`models/monitor/best_model.h5`；指标：`results/monitor/`。

---

## 1. 流程

```text
长音频
 → 重采样/单声道
 → 四阶巴特沃斯带通 + 预加重
 → 25 ms 分帧、10 ms 帧移、汉明窗
 → 短时能量自适应阈值端点检测（间隔 ≤150 ms 合并）
 → MFCC 13 + Δ 13 + Δ² 13 = 39 维/帧，统一 101 帧
 → CNN-BiLSTM 二分类
 → 概率 ≥ 阈值 → 候选事件
 → 2 s 冷却合并 → 事件列表
 → 频次/分钟 → normal / warning / danger
```

**训练与推理必须同构**：训练用端点检测切段，推理也优先用端点检测；只有完全切不出有效段时才退回滑窗。这是实际踩过的坑，否则长录音会大量漏检。

---

## 2. 预处理

| 步骤 | 方法 | 参数 | 作用 |
|---|---|---|---|
| 带通 | 四阶巴特沃斯 | 100–2000 Hz（基础配置） | 滤除风机低频与高频噪声 |
| 预加重 | 一阶高通 `H(z)=1−0.97z⁻¹` | α=0.97 | 补偿高频衰减，突出共振峰 |
| 分帧 | 汉明窗 | 25 ms / 10 ms | 短时平稳假设，减少频谱泄漏 |
| 端点检测 | 短时能量 + 自适应阈值 | `TE = μ_E + 0.5σ_E` | 切出有效段，剔除静音 |
| 间隔合并 | 相邻有效帧合并 | ≤150 ms | 避免一声咳嗽被切碎 |
| 兜底 | 固定时长截取 | 无有效段时 | 保证样本不丢 |

**调参实验（独立于交付模型）**：把带通放宽到 50–4000 Hz、梅尔上限设为 4000 Hz、滤波器数 24→32、阈值 0.4→0.2。原因：自有数据大量为 8 kHz 采样，有效带宽只有 0–4 kHz，原参数把 82% 的滤波器铺在没有信号的频段上。该实验脚本为 `scripts/16_tuned_run.py`、`scripts/17_fair_compare.py`，**未替换生产模型**。

---

## 3. 特征：39 维 MFCC

```text
分帧信号 → FFT(n_fft=2048) → 功率谱 → 24/32 个梅尔三角滤波器
→ 取对数 → DCT → 前 13 维 MFCC
→ 一阶差分 13 维 + 二阶差分 13 维
= 39 维/帧，统一到 101 帧
```

- 13 维静态 MFCC：当前帧的音色/谱包络；
- Δ/Δ²：音色变化的速度与加速度，对应咳嗽“突然爆发—快速衰减”的特点；
- 统一 101 帧：不足补零、超出截断，保证网络输入固定。

> 注意：监测模块是 44.1 kHz、25/10 ms、39 维；辨病模块是 16 kHz、1 s、84 维。两套口径独立，不要混用。

---

## 4. 模型：CNN-BiLSTM

```text
输入 (101, 39, 1)
 → Conv2D(32, 3×3) + ReLU + MaxPool(2×2)
 → Conv2D(64, 3×3) + ReLU + MaxPool(2×2)
 → TimeDistributed(Flatten)  # (25, 576)
 → BiLSTM(64, return_sequences=True)
 → BiLSTM(32)
 → Dense(64, ReLU) + Dropout(0.3)
 → Dense(2, Softmax)
```

- 参数量 **392,514**（约 1.5 MB 参数），`best_model.h5` 文件约 4.8 MB；
- CNN 负责局部频谱模式（共振峰、能量集中区），BiLSTM 负责时序上下文；
- 训练：Adam lr=0.001、batch=32、最多 150 轮、早停 20 轮、学习率衰减 8 轮、类别加权、数据增强（时间拉伸 0.9–1.1、音高 ±2、加噪 SNR 5–15 dB、时移）。

---

## 5. 推理与预警

- 单段：`predict_audio_file()` → `prob_cough / prob_non_cough / label`；
- 长音频：端点分段优先 → 逐段分类 → 概率 ≥ `CONFIDENCE_THRESHOLD` 记为候选 → 2 s 冷却合并；
- 频次：咳嗽次数 / 分钟；
- 预警：`<5 normal`、`5–15 warning`、`≥15 danger`（可在配置中调整）。

当前 `monitor/config.py` 默认阈值 **0.4**；调参实验建议在早期预警场景用 **0.2 + 累计告警**（10 分钟内累计 ≥3 次才触发），以降低偶发误报。换猪场/设备后必须重新扫阈值曲线。

## 8. 踩坑与处理

| 问题 | 原因 | 处理 |
|---|---|---|
| 论文 `n_fft=512` 与 25 ms@44.1 kHz 矛盾 | 25 ms 有 1102 点，512 点 FFT 覆盖不了整帧 | 保留 25 ms，`n_fft=2048` 零填充 |
| 端点检测切出 0 段 | 自适应阈值对短样本偏高，碎片达不到 0.2 s | 150 ms 间隔合并 + 无有效段时整段兜底 |
| 长录音漏检 | 训练用端点分段，推理用固定滑窗，分布不一致 | 推理改为端点分段优先，滑窗兜底 |
| 概率挤在 0.5 附近 | 小样本 + 未标准化 | 训练集统计 mean/std，推理复用 `feature_scaler.npz` |
| 类别不平衡 | 咳嗽 359 / 非咳嗽 181 | 类别加权 + 数据增强 |
| 带通参数水土不服 | 论文数据 44.1 kHz，本项目大量 8 kHz | 调参实验放宽到 50–4000 Hz、fmax=4000 |

## 9. 局限

- 540 个样本，场景/设备集中，跨猪场泛化未验证；
- 单麦克风，无法定位个体；
- 文件级严格留出 92.59%，仍有 2 个漏检、2 个误报；
- 调参方案尚未替换生产模型，需重新训练并做跨场验证后再上线。
