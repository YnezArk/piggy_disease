# 04 运行、测试与部署

> 适用：本地开发、演示、服务器部署。所有命令默认在项目根目录 `D:\Coding\Project\音识咳` 执行。

---

## 1. 环境

| 项 | 要求 |
|---|---|
| Python | 3.10+（3.14 可跑辨病/论治；监测的 TensorFlow 建议 3.10/3.11） |
| MySQL | 8.0，两个库：`pig_diag_v2`、`pig_cough_dataset` |
| 大模型 | OpenAI 兼容网关（阿里云百炼或自建），需 `DASHSCOPE_API_KEY` |
| 监测 | TensorFlow（Windows 原生仅 CPU）、Flask |
| 论治 | openai、fastapi、uvicorn、jieba |

```bash
python -m pip install -r requirements/base.txt
python -m pip install -r requirements/prescription.txt
python -m pip install -r requirements/monitor.txt   # 含 TensorFlow
```

## 2. 配置

```bash
cp .env.example .env
```

`.env` 关键项：

| 变量 | 说明 |
|---|---|
| `DASHSCOPE_API_KEY` | 网关 Key |
| `DASHSCOPE_BASE_URL` | OpenAI 兼容地址 |
| `DASHSCOPE_MODEL` | 当前 `qwen3.8-flash`（以 `.env` 为准） |
| `DASHSCOPE_ENABLE_THINKING` | `false` 关闭思考模式，显著降低延迟 |
| `DB_HOST/PORT/USER/PASS` | MySQL 公共连接 |
| `DB_NAME` | 诊疗库，默认 `pig_diag_v2` |
| `MONITOR_DB_NAME` | 监测库，默认 `pig_cough_dataset` |
| `MONITOR_API_TOKEN` | 监测 API Bearer Token；留空=不鉴权 |

> `.env` 已在 `.gitignore` 中；不要把真实 Key/密码写进代码或文档。

## 3. 数据库导入

```bash
mysql -u root -p < data/sql/pig_diag_v2.sql
mysql -u root -p < data/sql/pig_cough_dataset.sql
```

- `pig_diag_v2`：26 张表，辨证库/论治库/药材/禁忌/诊断记录/处方记录/声学特征等；
- `pig_cough_dataset`：监测样本、咳嗽事件、预警、去重表；
- 监测模块连不上库时会自动回退本地目录扫描；论治的 RAG 不依赖 MySQL（CSV/ txt），但 SQL 交叉验证与安全校验需要 MySQL。

## 5. API

### 5.1 论治（FastAPI，8000）

```bash
python prescription/api_server.py
# 或 python -m uvicorn api_server:app --app-dir prescription --port 8000
```

| 方法 | 路径 | 输入 | 输出 |
|---|---|---|---|
| POST | `/api/diagnosis` | JSON：`disease, symptoms, temp_c, weight_kg, severity, pig_extra` | 证型/组方/校验 + `trace_id` |
| POST | `/api/diagnose-audio` | multipart：`file` + 上述字段 + `model_name=sslr/svm` | 辨病 + 论治 + 落库 |
| GET | `/api/health` | — | `{"status":"ok"}` |

### 5.2 监测（Flask，5000）

```bash
python monitor/scripts/08_api_server.py
```

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/health` | DB/模型状态 |
| POST | `/api/predict` | 上传单段 `file` → 咳嗽概率 |
| POST | `/api/predict_long` | 上传长音频 → 事件列表 |
| GET | `/api/events` | 事件分页（`farm_code/start/end/page`） |
| GET | `/api/stats` | 近 N 分钟频次 + 预警级别 |
| GET | `/api/alerts` | 预警记录 |
| POST | `/api/monitor/start` | 启动文件夹监测 |
| POST | `/api/monitor/stop` | 停止 |
| GET | `/api/monitor/status` | 运行状态 |

### 5.3 监测 Docker 服务（8000）

```bash
cd deploy/monitor
docker compose up -d --build
```

- `POST /api/monitor`：JSON `{audioUrl, shedInfo, temperature, mentalState}`；
- 返回：`{code, message, data:{status, coughRate, confidence, details:{coughCount, averageInterval}}}`；
- `GET /health`、`GET /static/<file>`；
- `docker-compose.yml` 从环境变量读取 `DB_*`、`MONITOR_DB_NAME`、`MONITOR_API_TOKEN`。

## 8. 常见问题

| 现象 | 原因 | 处理 |
|---|---|---|
| `Can't connect to MySQL ... (10061)` | MySQL 服务未启动 | 启动 MySQL 服务；确认 `.env` 的 host/port |
| `ModuleNotFoundError: tensorflow` | 当前 Python 没装 TF | 用 Python 3.10/3.11 环境安装 `requirements/monitor.txt` |
| 论治单次 100 s+ | Qwen 默认开思考模式 | `.env` 设 `DASHSCOPE_ENABLE_THINKING=false`，重启进程 |
| API 401 | 设置了 `MONITOR_API_TOKEN` 但请求未带 Bearer | 加 `Authorization: Bearer <token>`，或清空该变量本地联调 |
| `ModuleNotFoundError: config` 且两个模块同时导入 | `monitor` 与 `prescription` 都有 `config.py` | 分开进程运行；不要在同一进程同时 import 两个模块 |
| 监测找不到模型 | 路径未按根目录解析 | 确认 `models/monitor/best_model.h5` 存在，配置指向根目录 |
| 端口占用 | 5000/8000 已被占用 | 换端口或停止旧进程 |
