# 数据目录说明

把**人工标注好**的音频按类别放入以下两个目录（命名随意，支持 wav/mp3/flac/ogg）：

```
data/raw/
├── cough/        # 咳嗽正样本（猪咳嗽声）
│   ├── xxx_01.wav
│   └── ...
└── non_cough/    # 非咳嗽负样本（呼噜、尖叫、哼哼、吃食声、风机噪声、金属碰撞声等）
    ├── yyy_01.wav
    └── ...
```

标注建议（参考设计文档 3.1 节）：
- 在兽医/饲养员指导下，用 Adobe Audition 人工截取、标注；
- 目标样本量 ≥ 1000 个，正负样本尽量均衡；
- 采样率建议 44.1kHz / 16bit / 单声道（与 `config.py` 一致，其它采样率会自动重采样）；
- 每个样本尽量只包含一个声音事件，便于端点检测与固定长度对齐。

训练数据整理：`python scripts\10_build_retrain_dataset.py`（从 monitor_in\pig_cough_data 按病种整理），
用于验证整条 pipeline 能跑通（**演示数据不能代表真实识别精度**）。
