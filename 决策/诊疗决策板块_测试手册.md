# 诊疗决策板块 — 手动测试手册

> 配套脚本：`test_manual.py`（分块运行，逐项 [PASS]/[FAIL]，末尾汇总）
> 前置条件：MySQL 运行 + `.env` 含 API Key + 联网（LLM 调用）

## 一、运行方式

```bash
# 全部测试（API 块需要先启动服务）
python test_manual.py all

# 只跑某一块
python test_manual.py env      # 环境检查（快，不调LLM）
python test_manual.py rag      # RAG 检索质量（快）
python test_manual.py safety   # 安全校验（快）
python test_manual.py cases    # 论治引擎端到端（慢，调LLM，4案例约1-2分钟）
python test_manual.py sql      # 数据库查询（快）
python test_manual.py api      # API 服务（需先启动）

# 交互菜单
python test_manual.py
```

API 服务启动：
```bash
python -m uvicorn api_server:app --host 127.0.0.1 --port 8000
```

## 二、测试样例总览

### 2.1 论治引擎端到端（4 个标准案例）

| 案例 | 输入（辨病+症状+体征） | 预期辨证 | 预期组方方向 |
|------|----------------------|---------|-------------|
| **A** | 猪支原体肺炎 / 湿咳、痰多、呼吸粗、食欲下降 / 39.2℃ / 70kg / 中度 | **疫热壅肺**（中期） | 清肺散/迎甘组方/麻杏石甘散 |
| **B** | 猪流感 / 干咳、鼻流清涕、突发高热、精神萎靡 / 40.5℃ / 50kg / 轻度 | **邪袭肺卫**（前期） | 银翘散（兽用） |
| **C** | 猪肺疫 / 咳嗽、呼吸困难、颈部肿胀、便秘 / 40.8℃ / 80kg / 重度 | **疫热壅肺**（中期） | 清肺散/麻杏石甘散 |
| **D** | 混合感染 / 咳嗽喘促、精神萎靡、病程长、反复发作 / 38.5℃ / 60kg / 重度 | **气阴两伤**（后期） | 生脉散加减 |
| **E** | ⭐**辨病纠错**：上游错判"猪支原体肺炎"，实际症状 突发高热40.5℃、干咳阵咳、鼻流清涕、全群爆发 / 50kg / 轻度 | **邪袭肺卫**（按症状独立辨证，不被锚定）+ **conflict=true**（双重交叉验证指出矛盾） | 银翘散（兽用） |

**检查要点**：
1. 辨证证型与上表一致（LLM 表述可能有措辞差异，包含关键词即通过）
2. `references` 字段非空（必须引用检索库来源）
3. 校验 `safe=True`（无十八反/幻觉剂量硬拦截）
4. 组方含 3-8 味药、有剂量、有用法疗程
5. **案例E（纠错）**：`rule_cross_check.conflict=true` + `disease_conflict.conflict=true`，
   `evidence_disease` 指向猪流感——双重交叉验证必须指出上游辨病错误

## 三、手动自由测试（自定义输入）

直接调论治引擎：

```python
from therapy_engine import treatment_pipeline
import json

# 改这里的输入即可
r = treatment_pipeline(
    disease="猪支原体肺炎",        # 辨病模型输出（5选1：支原体/流感/肺疫/胸膜肺炎/混合感染）
    symptoms="湿咳、痰多、呼吸粗", # 症状描述，越具体辨证越准
    temp=39.2,                    # 体温℃（38-42）
    weight=70,                    # 体重kg（5-200）
    severity="中度",              # 轻度/中度/重度
    pig_extra="4月龄育肥猪",      # 补充信息
)
print(json.dumps(r, ensure_ascii=False, indent=2))
```

调 API（模拟前端调用）：

```python
import json, urllib.request
payload = {
    "disease": "猪流感", "confidence": 0.88,
    "symptoms": "干咳、鼻流清涕、突发高热",
    "temp_c": 40.5, "weight_kg": 50, "severity": "轻度",
    "pig_house": "第3圈第2舍", "pig_extra": "生长猪",
}
req = urllib.request.Request("http://127.0.0.1:8000/api/diagnosis",
    data=json.dumps(payload).encode("utf-8"),
    headers={"Content-Type": "application/json"})
with urllib.request.urlopen(req, timeout=180) as resp:
    print(json.dumps(json.loads(resp.read().decode("utf-8")), ensure_ascii=False, indent=2))
```

## 四、边界/异常测试建议

| 场景 | 输入 | 预期行为 |
|------|------|---------|
| 未知疾病名 | disease="随便写的病" | 辨证Agent 标注"缺检索依据"，不编造出处 |
| 体温异常 | temp=45.0 | 辨证库无规则命中 → 低置信度输出 |
| 空症状 | symptoms="" | 不崩，辨证基于辨病结果 |
| 极重病情 | severity="重度" + 大体重 | 剂量换算放大，校验提示 |
| 十八反混入 | 组方里加"甘遂" | 校验硬拦截 |
| API 无服务 | 不启动 uvicorn 跑 api 块 | 提示启动命令，不算崩溃 |
