#### 子步骤 1c：规则交叉验证（非 LLM，确定性，别名归一）

```
调用: rule_cross_check(disease="猪流感", temp=42.0, keyword="高热 呼吸困难 喘促 犬坐 高热 犬坐")

  ① 先做疾病别名归一加载: MySQL disease 表 → {病名: {name + alias展开}}

  ② sql_syndrome_lookup(42.0, "高热...犬坐") → 同上3行
  ③ 逐行检查（别名归一比较 _same_disease）:
     rows[0].disease="猪流感" vs upstream="猪流感" → 一致 ✓
     rows[1].disease="猪传染性胸膜肺炎" vs upstream="猪流感" → 不同
     rows[2].disease="" vs upstream → 跳过(无标注)
  ④ 语义判定（2026-08-09 重构）:

    "checked": true,
    "hits": [

      {"syndrome": "疫热壅肺", "disease": "猪传染性胸膜肺炎",   "weight": 8},

**数据流转**：
```
